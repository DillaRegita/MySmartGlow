# SmartGlow App

SmartGlow is an Android-based mobile application developed to control and monitor an IoT-based smart lighting system.

## 📱 Project Overview

SmartGlow is designed to provide users with an easy-to-use mobile interface for controlling a smart lamp. The application supports automatic and manual lighting control and is integrated with an IoT system.

The project combines mobile application development with IoT technology to create a smart lighting solution that can respond to environmental light conditions.

## ✨ Features

* Automatic lighting control based on light intensity
* Manual lamp ON/OFF control
* Light intensity monitoring
* IoT-based smart lighting control
* Android mobile application interface

## 🛠️ Technologies

* **Kotlin** — Android application development
* **Android Studio** — Development environment
* **ESP32** — IoT microcontroller
* **BH1750** — Light intensity sensor
* **IoT** — Smart lighting system

## 🏗️ System Architecture

```text
BH1750 Light Sensor
        ↓
      ESP32
        ↓
   IoT System
        ↓
   Smart Lamp
        ↕
  SmartGlow App
```
